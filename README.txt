# TaskMaster HTML
Abra `index.html` no navegador ou no VS Code com Live Server.

Inclui:
- Dashboard
- Tarefas: criar, concluir, excluir e filtrar
- Despesas: adicionar e excluir
- Relatórios
- Perfil
- Configurações
- Notificações
- Modo claro/escuro com persistência
- Layout responsivo para celular e desktop
